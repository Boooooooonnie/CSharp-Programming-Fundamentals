# C# Programming Fundamentals

A collection of C# console programming exercises completed during my programming coursework.

This repository documents my practice with fundamental C# programming concepts, including console input and output, control structures, data validation, classes, properties, constructors, and basic object-oriented programming.

## Topics Covered

- Console input and output
- Variables and data types
- Conditional statements
- Loops and iteration
- Input validation
- Classes and objects
- Properties and constructors
- Basic object-oriented programming
- Simple data processing and calculations

## Exercises

| Project | Description |
| --- | --- |
| Basic Console Operations | Basic console input, formatted output, arithmetic operations, and number comparison |
| Account Class Basics | Introductory object-oriented programming exercises using classes, properties, and constructors |
| Student Grade System | Uses a Student class to store grades and determine letter grades |
| Class Average Calculator | Calculates the average of multiple grades using iterative input |
| Validated Grade Average | Validates grade input and calculates the total and average |
| Largest Number Finder | Finds the largest and second-largest values from a set of numbers |
| Bank Account System | Implements basic account operations including deposits, withdrawals, and balance validation |
| Student Record System | Stores and updates student information and calculates academic results |
| Grade Average Calculator | Calculates the total and average for a specified number of grades |
